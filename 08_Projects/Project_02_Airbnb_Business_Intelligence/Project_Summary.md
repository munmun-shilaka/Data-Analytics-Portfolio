# Project Summary

## Project Title

NYC Airbnb Business Intelligence & Market Strategy Analysis

## Objective

Analyse the New York City Airbnb market using real-world listing, review, neighbourhood, and availability data to identify pricing patterns, host behaviour, customer engagement, and market opportunities.

## Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- SQLite
- SQL
- Power BI (dashboard planned)
- Git & GitHub

## Data Sources

The project uses publicly available NYC Airbnb data covering:

- Listings
- Reviews
- Neighbourhoods
- Calendar availability

## Dataset Scale

- 30,555 listings
- 16,474 hosts
- 223 neighbourhoods
- 5 boroughs
- 990,170 reviews
- 11M+ calendar records

## Analysis Components

### Python

- Data loading
- Data quality assessment
- Missing-value analysis
- Exploratory data analysis
- Feature engineering
- Market segmentation
- Visual analytics

### SQL

Eight structured SQL analysis modules were developed:

1. Database Setup
2. Data Exploration
3. Business KPIs
4. Revenue & Availability Analysis
5. Host Analysis
6. Pricing Strategy
7. Customer Insights
8. Executive Report

### Business Intelligence

The analysis is designed to support:

- Pricing decisions
- Host segmentation
- Neighbourhood strategy
- Customer engagement analysis
- Market opportunity identification

## Final Deliverables

- Python analysis notebook
- SQLite database
- Business SQL scripts
- Executive report
- Data dictionary
- Business report
- Power BI dashboard (planned)
- GitHub documentation

## Key Outcome

The project transforms a large public Airbnb dataset into a structured business intelligence workflow combining data analysis, SQL, business interpretation, and dashboard-ready outputs.

**Data Analytics → SQL → Business Intelligence → Data Storytelling → Strategic Recommendations**
