# Power BI Dashboard

## Overview

This folder is reserved for the Power BI dashboard version of the Amazon Product Analytics project.

The dashboard will include:

- Executive KPI Dashboard
- Product Category Analysis
- Rating Distribution
- Discount Analysis
- Price Analysis
- Business Insights
- Interactive Filters
- Slicers for Categories

## Dashboard KPIs

- Total Products
- Average Rating
- Average Discount
- Average Price
- Total Categories
