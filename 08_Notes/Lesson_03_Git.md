# Lesson 03 - Git


## What is Git?
Explain that Git is a version control system.
Mention that it tracks changes in files.

## Why was Git created?
Explain that it helps avoid confusion caused by multiple versions of the same project.

## What is Version Control?
Explain that version control stores the history of project changes.

## Git vs GitHub
Explain that Git is software installed on your computer, while GitHub is an online platform for hosting Git repositories.
